# Hello World

## Problem Statement

There is no minimal, working starting point to confirm the platform can take a product from idea to a running app. A simple greeting page is enough to prove it.

## Solution

A single public web page that greets the visitor with "Hello, World!".

## Actors

- Visitor: anyone who opens the app; sees the greeting. No sign-in.

## Features

- F1 [Greeting](features/F1-greeting.md)

## Product-wide

See [Product-wide](product-wide.md).

## Out of Scope

- Sign-in or user accounts.
- Personalised greetings.
- A separate greeting API.
